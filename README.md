# Проект "cv_constructor"

## Цель проекта

Веб-приложение для создания, редактирования и генерации CV/резюме на основе шаблонов c использованием LLM, анализа содержимого и экспорта в разные форматы.

## Используемые технологии и инструменты

- Node.js, Express
- MongoDB, Mongoose
- HTML, CSS (Tailwind CSS, собственные стили), JavaScript (frontend)
- Шаблоны CV в виде HTML и DOCX
- Интеграция с LLM (Google Generative AI, Groq)
- Stripe (платежи)
- Jest (тестирование)

## Инструкции по запуску и использованию

1. Установите зависимости:
   - `npm install`
2. Настройте переменные окружения в файле `.env` (MongoDB, ключи LLM, Stripe и др.).
3. При необходимости соберите стили Tailwind CSS:
   - `npm run build:css`
4. Запустите сервер:
   - `npm start`
5. Откройте в браузере страницу `http://localhost:3000` (или указанный в конфигурации порт) и используйте интерфейс для создания и редактирования CV.

## Структура приложения

- `index.js` — точка входа backend-приложения (Express-сервер).
- `config/` — конфигурация базы данных.
- `models/` — модели Mongoose (пользователь, CV, Assessment и др.).
- `routes/` — API-маршруты (аутентификация, работа с CV, пользователями).
- `middleware/` — middleware, включая аутентификацию.
- `services/` — сервисы для валидации CV, генерации HTML, работы с LLM, анализа PDF и т.п.
- `public/` — статические файлы (HTML-страницы, CSS, JS, изображения, шаблоны CV).
- `uploads/` — сгенерированные резюме и временные файлы для PDF-шаблонов.
- `__tests__/` — модульные тесты (например, валидация CV).
